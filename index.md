# Arcanum Lux

Мобильное приложение для работы с картами Таро: карта дня, расклады,
справочник из 78 карт с подробными трактовками и личный дневник.
Доступно на русском, английском и казахском языках.

Приложение создано для развлечения и саморефлексии.
